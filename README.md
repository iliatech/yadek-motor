# یدک موتور: Persian Parts Hub

Create the initial version of a Persian RTL e-commerce website for a small motorcycle spare parts store.

The temporary brand name is:

یدک موتور

This project is a real future e-commerce store, but in this phase ONLY build the frontend structure, design system, and homepage.

Do not implement authentication, database, payment, checkout, admin panel, or backend yet.

The website must be completely in Persian and fully RTL.

Brand identity

The visual identity should combine:

Industrial
Minimal
Dark
Premium
Professional

The store sells motorcycle spare parts and accessories.

However, avoid making the website look like a racing website, gaming website, or a generic car dealership.

The feeling should be similar to a modern, professional, specialized industrial parts store.

Visual design

Use:

Deep charcoal and near-black backgrounds

Dark gray surfaces

White and light gray typography

One restrained industrial accent color

Thin subtle borders

Clean geometric layout

Generous spacing

High-quality product imagery

Subtle and smooth hover animations

Minimal gradients

Strong visual hierarchy

Do not use excessive bright colors.

Do not use excessive red.

Do not create a flashy or futuristic cyberpunk design.

The interface should feel trustworthy, elegant, modern, and technical.

Use a modern Persian font that supports excellent readability.

RTL requirements

The entire website must use proper RTL layout.

All text, navigation, buttons, forms, icons, and page structure must work correctly in RTL.

All visible text must be natural Persian.

Use تومان for all product prices.

Homepage structure

Create the following sections:

1. Header

Create a premium sticky header.

Include:

Logo area with the text "یدک موتور"

Main navigation

A prominent search icon or search access

User account icon

Shopping cart icon with item count

Navigation items:

خانه
فروشگاه
دسته‌بندی‌ها
درباره ما
تماس با ما

The header should remain minimal and uncluttered.

2. Hero section

Create a large, visually strong hero section.

Main heading:

قطعه‌ای که نیاز داری، همین‌جاست.

Supporting text:

قطعات و لوازم یدکی موتورسیکلت را سریع، ساده و مطمئن پیدا کن.

Add a large product-oriented search bar.

Placeholder:

دنبال چه قطعه‌ای هستید؟

Below the search bar, add quick search suggestions:

لنت ترمز
شمع
زنجیر
روغن موتور
چراغ جلو

The search bar should be the central interaction of the hero section.

The visual background should be subtle and industrial, possibly using abstract motorcycle mechanical forms, spare parts, metal textures, or technical details.

Do not make the background too busy.

3. Product categories

Create a section titled:

دسته‌بندی قطعات

Create elegant category cards for:

قطعات موتور
سیستم ترمز
سیستم برق
زنجیر و انتقال قدرت
روغن و مواد مصرفی
بدنه و لوازم جانبی

Each category should have a simple relevant icon or visual.

4. Featured products

Create a section:

محصولات منتخب

Show 6 realistic sample motorcycle spare parts.

Each product card should contain:

Product image

Product name

Brand

Price in تومان

Availability indicator

Add to cart button

Use realistic Persian product names.

Do not use Lorem Ipsum.

Example products:

لنت ترمز جلو
شمع موتور
زنجیر موتورسیکلت
روغن موتور
دیسک ترمز
آینه موتور

Do not make all cards identical in visual appearance. Keep them clean and consistent but realistic.

5. Why us

Create a minimal section titled:

چرا یدک موتور؟

Include:

ارسال سریع
خرید مطمئن
قیمت شفاف
پشتیبانی

Use minimal industrial-style icons.

6. Final CTA

Create a simple section encouraging users to explore the store.

Text:

قطعه مورد نیازت را پیدا کن

Button:

مشاهده فروشگاه

7. Footer

Create a professional footer.

Include:

یدک موتور

Links:

درباره ما
تماس با ما
قوانین و مقررات
روش ارسال

Also include placeholders for:

شماره تماس
آدرس
شبکه‌های اجتماعی

Important UI requirements

The website must:

Be fully responsive

Look excellent on mobile

Have a polished desktop layout

Use reusable components

Use clean TypeScript

Use a maintainable component structure

Do not build a generic landing page.

This must clearly look like the homepage of a real Persian online motorcycle spare parts store.

Do not implement backend functionality yet.

Use sample data only for this phase.

At the end, review the page for:

RTL correctness

Persian text quality

Mobile responsiveness

Visual consistency

Broken layouts

Fix any issues you find before considering Phase 1 complete.
